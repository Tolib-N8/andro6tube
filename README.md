# Andro6Tube

Лёгкий YouTube-клиент для головного устройства на Android 6.0.1 (TI DRA74X).

- Только H.264 + AAC: видео декодирует аппаратный блок IVA-HD, а не процессор, поэтому без лагов.
- Кнопки руля (след./пред./пауза) работают и в приложении, и в фоне через MediaSession.
- Управление джойстиком/крутилкой: яркая жёлтая рамка фокуса. В плеере на видео ←/→ перематывают на ±10 с, OK ставит паузу.
- История с продолжением с места остановки и список «Смотреть позже» (долгое нажатие или кнопка «Меню» на видео).
- Звук продолжает играть в фоне, видеодорожка при этом отключается.

## Установка по ADB

```sh
adb connect <IP-ГУ>:5555          # если по Wi-Fi
adb install -r dist/Andro6Tube.apk
```

## Обновления через GitHub

Приложение берёт обновления из Releases репозитория `Tolib-N8/andro6tube`.
В машине: «Настройки → Проверить обновления». Приложение покажет версию и описание, скачает APK и поставит.
С root ставит само, без root появится системное окно «Установить».

Выпустить обновление:

```sh
./scripts/release.sh 1.0.1 "Что нового"
```

Скрипт поднимает версию, собирает подписанный APK и создаёт релиз `v1.0.1` с этим APK.
Вручную через сайт: тег `vX.Y.Z` больше текущей версии, к релизу прикрепить `.apk`,
подписанный ключом из `keystore/` (собирать через `./gradlew assembleRelease`).

**Ключ подписи** (`keystore/andro6tube.jks` + `keystore.properties`) нельзя терять и публиковать.
Без него обновление не встанет поверх: придётся удалять приложение и ставить заново через ADB.
Сделайте резервную копию обоих файлов. Они в `.gitignore`.

## Диагностика

- «Настройки → Тест кнопок» показывает коды кнопок руля и джойстика.
  Если какая-то кнопка не работает, пришлите её код.
- `adb logcat -s A6Keys A6Player A6Source` — нажатия, ошибки, выбранный поток и декодер.
  Строка `video decoder: OMX.TI...` означает, что работает аппаратный декодер.
- В «Настройках» внизу есть список декодеров устройства с пометками [HW]/[SW].

## Сборка

```sh
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
./gradlew assembleRelease   # → app/build/outputs/apk/release/app-release.apk
```

Если YouTube сломает извлечение, поднимите `newpipeExtractor` в `gradle/libs.versions.toml` и пересоберите.
